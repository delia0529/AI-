大厂战略 / 模型架构
核心事实

Meta 发布 Muse Wonder 与 Muse Wonder Full，称其在个人与专业 Agent 任务上达到当前最佳水平；Zuckerberg 表示 Meta 已在 AI 前沿追上对手，并拒绝放缓的呼吁。Wonder 通过 Meta Model API 与 Muse Code 提供，Wonder Full 面向 Muse Code 订阅用户，并将首先用于驱动 Muse。
